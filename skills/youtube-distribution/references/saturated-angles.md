# Saturated angles: check before using

Using one of these needs a genuinely new twist and outlier data showing it still works **this month**.

- Doom AI ("AI will take your job")
- "X skills to learn before AI replaces you"
- Money-promise thumbnails (₹10 Cr, 10X income, "how I made ₹1 Cr")
- "SaaS is dead"
- Celebrity-net-worth and "how rich is X" explainers
- "I tried X for 30 days"

## Keep this list alive

Add an angle when 3+ recent outlier searches show the same promise from many channels with falling multiples. Remove one when it stops being everywhere.
